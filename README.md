# Worst Monday One-Liners

One funny line about an AI agent's worst Monday, written by a small
deterministic program for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) competition on make.fun.
